## ⚡ Cara Menjalankan Aplikasi

```bash
# 1. Masuk ke direktori roombook
cd roombook

# 2. Instal dependensi (jika belum)
npm install

# 3. Jalankan server lokal
npm run dev
```

Buka browser di: **`http://localhost:3000`**
